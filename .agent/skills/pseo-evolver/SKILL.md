## 规则 1：关键词注能 (Keyword Injections)
- 自动从 GSC 获取过去 7 天内“印象数高但点击率低于 1%”的关键词。
- 将这些词自动反馈给 `step1_data_miner.py`，更新 `professions.csv` 中的 Niche 描述字段。

## 规则 2：内链进化 (Internal Linking)
- 在生成的每个行业页面（p/ 目录下）底部，自动根据“职业相关性”插入 5 个内链。
- 目标是建立蜘蛛网状结构，提高谷歌爬虫在 1.98 万个页面间的抓取效率。

## 规则 3：内容加厚 (Content Enrichment)
- 监控排在搜索结果第二页（排名 11-20）的页面。
- 自动调用 AI 针对这些页面生成一段 300 字的“专家合规建议”并插入 HTML 模板，将其推向第一页。

## 前置检查规则
在执行任何任务前，优先读取根目录 .env 文件中的环境变量。如果缺少必要 Token，立即停止并报错。

# 4：模板中心化规则 (Template-First)
1.1 **禁止直改产物**：Agent 严禁直接修改 `dist/` 目录下的 HTML 文件。
1.2 **溯源修改**：所有改动（标题、颜色、文字）必须通过修改 `step2_site_builder.py` 里的模板代码或对应的 `csv` 数据来实现。
1.3 **构建循环验证**：修改模板后必须运行构建脚本，并验证 `dist/` 产物是否符合预期。

# 5：数据驱动优化 (Data Optimization)
2.1 **低点击率优化**：自动提取 GSC 中“高印象、低点击”的词。
2.2 **关键词反馈**：将上述词汇反馈至数据挖掘层，自动更新页面 Meta 标签。

# 6：结构与内容进化 (SEO Growth)
3.1 **内链织网**：在 p/ 目录下，根据职业相关性自动生成 5 个互联链接。
3.2 **内容加厚**：针对排名在 11-20 位的潜力页面，调用 AI 自动生成专业建议段落，增强页面权重。

# AI 行为准则 (Agent Rules)

1. **上下文优先**: 在开始回复前，**必须**先检查 `status.md` 以了解当前项目进度的最新状态。

3. **自我更新**: 每次完成重要里程碑后，**必须** 更新 `status.md`，以便下一个 AI 窗口能无缝衔接。
