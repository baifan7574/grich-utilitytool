## 规则 1：隐形广告位 (Ads Injection)
- 自动修改 `step2_site_builder.py` 里的 HTML 模板。
- 在页面 H1 标题下方和 PDF 工具操作区下方，精准插入 AdSense 广告位。
- **预案**：针对中国大陆 IP 访问，自动隐藏高延迟广告，改用本地化引导文案。

## 规则 2：订阅拦截器 (Subscription Funnel)
- 监控前端 PDF 处理工具（合并、审计等）的使用次数。
- 识别到同一用户在 24 小时内操作超过 3 次时，自动激活“合规报告下载”的付费订阅入口。

## 规则 3：变现健康检查 (Revenue Audit)
- 自动对比“流量点击数”与“广告展现数”。
- 如果发现某类职业页面流量大但没收益，自动尝试切换变现模板（如从广告切换为 Affiliate 链接）。

## 核心任务

1\. \*\*连接性体检\*\*: 自动检测 Cloudflare 域名解析状态及边缘计算节点（Pages/Workers）的响应速度。

2\. \*\*GSC 自动化\*\*: 

&nbsp;   - 检查网站根目录下是否存在 Google 验证文件。

&nbsp;   - 如果缺失，自动生成验证 HTML 并提示上传至 Cloudflare 存储。

&nbsp;   - 使用 Indexing API 获取当前的收录数量。

3\. \*\*pSEO 结构分析\*\*:

&nbsp;   - 扫描 Sitemap.xml，核对生成的页面数量与实际索引数量的差距。

&nbsp;   - 抽检 10 个页面，分析其 TDK（标题、描述、关键词）是否存在大量重复导致的“内容稀薄”风险。

4\. \*\*API 自动化监控\*\*:

&nbsp;   - 监控 API 调用的健康度（如果页面是动态生成的）。



\## 执行流程

\- \*\*第一步\*\*: 运行 `check\_dns\_and\_ssl` 工具。

\- \*\*第二步\*\*: 搜索项目中的验证文件（如 `google123.html`），若无，则调用 `generate\_verification\_file`。

\- \*\*第三步\*\*: 通过 GSC Search Analytics API 提取过去 16 个月的数据，分析流量是在何时断崖式下跌的。



\## 约束

\- 必须确报所有的页面在美国环境下的访问兼容性（CF 节点稳定性）。

\- 禁止大规模修改已收录的稳定页面，优先优化未收录页面。
