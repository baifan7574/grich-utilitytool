GRICH 项目：全自动流水线执行手册 (PM 专用版)

项目目标：构建一个基于 pSEO 的工具矩阵。通过 GitHub Actions 实现每月自动抓词、自动生成网页、自动部署 Cloudflare。
核心逻辑：静态网页拦截流量 + Cloudflare Functions 动态卖报告 ($4.99)。

阶段一：数据地基（生成关键词与差异化文案）

1. 你要发给反重力软件的指令 (直接复制)

"你现在是我的首席数据工程师。请编写一个名为 step1_data_miner.py 的 Python 脚本。

任务要求：

基础列表：内置美国 10 个州、10 个高隐私职业（Lawyer, Doctor, HR...）、6 个文档处理动作（Encrypt PDF, Merge PDF, Word to PDF...）。

数据清洗：交叉组合生成词条。创建一个函数模拟验证逻辑，确保关键词逻辑合理。

注入灵魂（差异化）：为每个组合生成一段 100 字左右的 SEO 描述。要求：律师对应的文案必须谈保密，医生对应的必须谈隐私协议，严禁文案高度重复。

数据库备份：除了生成本地 niche_data.csv，还要生成一份 SQL 脚本，以便将这些数据同步到 Cloudflare D1 数据库中作为备份。

请直接给我代码，我将在本地运行。"

2. 你如何验证 (验收标准)

动作：运行脚本后，你会得到一个 niche_data.csv。双击打开它。

标准：

[ ] 表格里是否有 500 行以上的数据？

[ ] 随机找两行，比如“德州律师”和“纽约医生”，看他们的描述文字是否明显不一样？

如果不合格怎么办？

纠错话术："描述文案太单一了，全是在重复一句话。请修改脚本中的描述生成逻辑，为每个行业建立一个关键词库，强制让描述具有行业特征。"

阶段二：生产线搭建（网页批量生成器）

1. 你要发给反重力软件的指令 (直接复制)

"数据已准备好。请编写第二个脚本 step2_site_builder.py。

任务要求：

高端 SaaS 模板：使用 Tailwind CSS 编写一个单页面 HTML 模板。背景纯白、大圆角、现代阴影效果。

主页设计：生成一个 index.html。必须包含：巨大的 Hero 标题、实时搜索框、按职业分类的导航卡片。

功能嵌入：引入 pdf-lib (CDN) 库。编写 JS 逻辑实现‘本地文件处理进度条’，100% 后弹窗提示购买‘合规报告’。

动态渲染：读取 niche_data.csv，将所有子页面生成到 dist/ 文件夹。注意：严禁在我本地电脑生成上万个文件，如果文件量大，请先只生成 20 个供我本地预览，剩下的逻辑要写在 GitHub Actions 里运行。

请给我完整的 Python 代码。"

2. 你如何验证 (验收标准)

动作：在本地打开 dist/index.html。

标准：

[ ] 页面看起来是否像个专业的 SaaS 软件？（不是简单的列表）。

[ ] 搜索框输入 "Texas"，下方的卡片是否会动态过滤？

[ ] 拖入一个 PDF，进度条跑完后，是否弹出了 $4.99 的提示框？

如果不合格怎么办？

纠错话术："界面太丑了，一点都不像 $4.99 的专业工具。请加强 Tailwind CSS 的样式设计，参考现代 SaaS 软件，增加更多阴影和间距，并优化搜索框的交互逻辑。"

阶段三：自动化流水线（GitHub Actions 部署）

1. 你要发给反重力软件的指令 (直接复制)

"现在我们要实现全自动化。请为我配置 .github/workflows/deploy.yml。

任务要求：

定时任务：设置每月 1 号北京时间凌晨 0 点自动触发。

云端运行：让 GitHub 的虚拟环境运行 step1 和 step2。

自动部署：使用官方 Action 将生成的 dist 目录自动推送到 Cloudflare Pages。

安全配置：请列出我需要在 GitHub Secrets 中配置的所有环境变量（如 API Token）。

请给出配置文件代码，并详细说明我该如何把本地代码推送到 GitHub。"

2. 你如何验证 (验收标准)

动作：将代码推送到 GitHub，查看 "Actions" 标签页。

标准：

[ ] 那个圆圈图标是否变绿了？

[ ] 访问你的 Cloudflare 域名，网页是否已经上线？

阶段四：收钱环节（API 报告生成器）

1. 你要发给反重力软件的指令 (直接复制)

"最后一步，我们需要处理付费后的报告。请在 functions/api/ 目录下编写 generate-report.js。

任务要求：

成本锁：接收前端传来的支付凭证。只有验证支付成功，才允许下一步。

API 调用：调用 OpenAI/DeepSeek API，根据参数生成 500 字的专业合规报告。

PDF 交付：将内容转为 PDF 返回给用户。

请给我代码，并确保它能直接在 Cloudflare Functions 环境运行。"

2. 你如何验证 (验收标准)

动作：部署后，点击页面上的“支付并生成”模拟请求。

标准：

[ ] 检查控制台：如果没有支付 ID，是否返回了报错？

[ ] 是否能成功下载到一个包含行业专业术语的 PDF 报告？

避坑与自救指南

1. 如果反重力软件写的代码报错了：

不要试图去读代码。直接把整个红色报错信息复制下来，发给它：

"运行 step1_data_miner.py 时报错了。报错信息如下：[粘贴报错内容]。请分析原因并给我修正后的完整代码。"

2. 如果它生成的网页太慢：

"现在的生成逻辑是把所有 CSS 都写在了每个 HTML 里，文件太大了。请将 CSS 抽离出来使用 CDN，或者优化 HTML 结构，确保 10,000 个文件生成时不会超时。"

3. 给你的最终建议：

先让它做 Step 1。等你在本地看到那个 .csv 表格并确认里面的文字“有灵魂”之后，再让它做 Step 2。切记：不要一次性让他写所有代码。
